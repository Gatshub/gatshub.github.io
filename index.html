Accueil Projets Sablaise

Développeur — outils en ligne de commande, applications mobiles, et ce qui les fait tourner.

J'ai repris la programmation à mon temps perdu, grâce aux outils d'intelligence artificielle. OpenCrabs, l'agent que je fais tourner au quotidien, et OpenRouter, qui lui ouvre l'accès à plusieurs modèles, ont rendu ce retour possible : je code à nouveau — des jeux et des outils pour le terminal, des applications pour le téléphone, et l'infrastructure qui se tient derrière.

Il me reste beaucoup de chemin à parcourir. Ce site montre un état de ce parcours, pas une arrivée.

Ce qui m'intéresse, c'est ce qui se vérifie. Un moteur de jeu se juge sur ses parties gagnées, une interface sur ce qu'elle laisse faire sans mode d'emploi, une API sur ce qu'elle tient. Le reste est une question de goût — et le goût compte aussi.

  • sudoku-tui

    Go · Terminal

    Un sudoku pour le terminal : grilles générées à solution unique, quatre niveaux, saisie au clavier, notes, indices, pause et minuteur. dépôt →

  • sudoku-mignon

    Go · Terminal

    Le même sudoku, repris entièrement par le goût : cadre arrondi, palette pastel lisible sur fond clair comme sombre, et un chiffre, une couleur — les neuf forment un arc-en-ciel. Le moteur est celui de sudoku-tui, éprouvé ; tout le travail est dans l'apparence.
